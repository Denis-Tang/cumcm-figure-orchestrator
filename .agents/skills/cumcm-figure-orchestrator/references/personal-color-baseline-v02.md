# 个人配色基线 V02

用户于 2026-09-08 确认 V02 为本 Skill 默认配色。精确色值见 `../assets/personal-color-baseline-v02.json`，视觉样张见 `../assets/personal-color-baseline-v02.png`。样张数据与流程均为假设，仅确立视觉基线，不规定正式论文的数据、图型数量或海报布局。

## 默认应用

- 共用明蓝、珊瑚红、暖橙、青绿、雾紫、蓝灰六色。按需取色，不必每图用满；同一对象在整篇论文中保持同色，颜色不够时增加点形、线型或分面，避免循环复用造成混淆。
- 折线、点、边框等小面积标记使用鲜明原色；散点重叠时可降低透明度，但不能暗示不存在的密度或权重。
- 柱状图、条形图、环形图、饼图等大面积分类色块，默认使用 `large_area_fills`：原色 76% + 白色 24%，模拟白底轻透观感。使用预混色，保持实际 alpha=1，避免网格透出或导出背景改变颜色。柱条配同色细轮廓；环形/饼图用细白色分隔。柱条不使用渐变，不加立体光影。
- 箱线图及流程节点使用 `soft_fills`：原色 16% + 白色 84%，搭配原色边框和深色文字。流程图与数据图共享色系；先维护语义映射，再安排色序。
- 白色为默认画布。只有背景确实表示阶段、分组或区域时才加入浅色背景，并明确标注语义。背景渐变也必须编码真实连续含义；不为装饰添加渐变。
- 热图和连续数值色标不能机械套用分类色。相关系数默认蓝—白—珊瑚红对应负—零—正，色限固定为 [-1,1]；其他连续量选语义合适、亮度有序的单色序列。色条须标注，跨图比较须统一尺度。不要把 76% 混色规则套到所有数值色标上。
- 标签、点形、线型辅助颜色辨识；检查最终论文尺寸及灰度可读性。必要时为可读性调整并记录原因。此基线是个人风格，不是国赛官方指定色板，不能取代科学严谨性或赛区格式要求。

## 覆盖与记录

默认直接使用，不重复询问是否采用。用户当次指定颜色时按其要求覆盖对应部分；未指定部分延续基线。将基线 ID、实际色值、对象映射和覆盖原因保存在批次绘图配置或来源记录中，并传递给下游 Skill/渲染器。新候选配色不自动替换本基线，须有用户明确确认。

# 个人配色基线与版本管理

V02 是 Developer 唯一的活动视觉基准，不支持多版本并行或版本切换。当前生效版本以 ../assets/personal-color-baseline.json 的 `baseline_id` 为准；读取实际色值和强度，不在绘图代码中硬编码版本。默认直接使用，无须再次确认。颜色数值与选择策略分层：策略见 personal-figure-style.md 和 ../assets/personal-figure-style.json。

| 版本 | 色系 | 柱条、环形等大面积分类填充 | 流程节点、箱线填充 |
|---|---|---|---|
| V02（唯一基准） | 明蓝、珊瑚红、暖橙、青绿、雾紫、蓝灰 | 原色 76% + 白色 24% | 原色 16% + 白色 84% |

版本快照：../assets/personal-color-baseline-v02.json，样张为同目录 personal-color-baseline-v02.png。V02 原始规则见 personal-color-baseline-v02.md。样张全部是假设数据，仅确立配色，不限制正式论文图型、数量和布局。

角色键 blue、coral、amber、violet、teal、slate 是逻辑名称，实际色值一律以当前 palette JSON 为准，不得按字面颜色名称自行推断。

## 图型应用

- 折线、点、边框使用 colors 原色，散点重叠可适度透明。柱条、环形和饼图使用 large_area_fills，alpha=1；柱条配同色细轮廓，环形和饼图用细白色分隔，不加渐变或立体光影。
- 流程节点、箱线使用 soft_fills 配原色轮廓与 text 深色文字。数据图和流程图共用语义映射，同一对象全篇同色。
- 按类别数选色，不必用满。配合点形、线型、标签或分面保证辨识，不把六色机械视作六个等价分类色。
- 默认白底；背景仅在表达阶段、区域或分组时用浅色并标注。背景渐变也须有连续语义，不作装饰。
- 连续数值色标独立遵循数据语义，不套用分类色序或大面积填充强度。相关系数使用 blue—白—coral 对应负—零—正，范围 [-1,1] 并标注色条；其他量使用语义合适且亮度有序的色标，跨图比较保持尺度一致。
- 检查最终尺寸、文字对比与灰度可读性，必要调整记录原因。这是个人配色，不是国赛官方指定色板，不替代科学审计和赛区要求。

## 覆盖与追溯

用户当次指定颜色时覆盖对应部分，其余延续当前基准。记录本次 baseline_id、实际色值和对象映射，并传递给下游 Skill/渲染器。

active JSON（../assets/personal-color-baseline.json）是唯一入口，其内容必须与 V02 快照逐字一致；如需校验一致性，将快照原样复制到入口后回读确认 `baseline_id=personal-cumcm-v02`。不覆写快照文件。后续若提出新方案，先在样张上打样，用户确认后再建立新版本并替换入口，不保留被否决方案的快照。

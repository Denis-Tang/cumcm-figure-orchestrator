# 个人配色基线：V02 Only

V02 是当前且唯一正式个人配色基线。`../assets/personal-color-baseline.json` 的 `baseline_id` 必须为 `personal-cumcm-v02`。

## 固定色值

| 角色 | HEX | 默认用途 |
|---|---|---|
| blue | `#2389DA` | 主方案、主体、计划值、首要分类 |
| coral | `#D95B52` | 对照、异常、紧急、负向强调、第二分类 |
| amber | `#E5A33D` | 第三分类、辅助强调 |
| violet | `#8876AF` | 第四分类、独立状态角色 |
| teal | `#49A88D` | 第五分类或确有绿色语义时使用 |
| slate | `#687D91` | 基准、reference、边界、次要上下文 |

`coral` 是内部 schema key；对用户可以称“红色”或“珊瑚红”，不因此修改 HEX 或 key。

## 选色优先级

简单分类图只使用完成科学表达所需的最少颜色：

1. 单一主系列：优先 `blue`。
2. 两个主要系列：优先 `blue + coral`。
3. 第三独立分类：增加 `amber`。
4. 第四独立分类：增加 `violet`。
5. 第五分类或明确绿色语义：再使用 `teal`。
6. `slate` 不参与上述分类色排序，始终保留为中性参考角色。

颜色顺序不是机械规则。若科学语义要求，应优先保持“主方案/正常状态”和“异常/风险/紧急状态”等对象在全篇的一致映射。

## 填充规则

- 折线、点、边框：使用 `colors` 原色。
- 柱条、环形、饼图等较大面积分类填充：使用 `large_area_fills`，对应约 76% 原色 + 24% 白色，`alpha=1`。
- 流程节点、箱线、语义背景：使用 `soft_fills`，对应约 16% 原色 + 84% 白色。
- 默认白底。背景色必须表达阶段、区域或分组，不用于装饰。
- 连续数值色标独立遵循数据语义，不机械套分类色优先级。

## 跨图语义一致性

同一对象在同一篇论文中尽量保持同色。同一含义的“计划 / 实际 / 紧急 / 基准 / 边界”等角色不得在不同图中任意换色。颜色不足时优先配合线型、marker、标签或分面，而不是无必要增加分类色。

## 与版式和 QA 的关系

配色规则不能覆盖科学表达规则。正式图仍需通过：

- `references/figure-style-contract.md` 中的 panel geometry、closed-frame、semantic smoothing 与 text clearance 规则；
- 最终论文尺寸下的文字、灰度、裁切和可辨识性检查；
- 数值与来源证据验证。

V02 是个人配色，不是 CUMCM 官方指定色板。

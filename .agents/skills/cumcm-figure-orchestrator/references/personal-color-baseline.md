## 图型应用

- 折线、点、边框使用 colors 原色，散点重叠可适度透明。柱条、环形和饼图使用 large_area_fills，alpha=1；柱条配同色细轮廓，环形和饼图用细白色分隔，不加渐变或立体光影。
- 流程节点、箱线使用 soft_fills 配原色轮廓与 text 深色文字。数据图和流程图共用语义映射，同一对象全篇同色。不要将 V03 兼容键名 teal/violet 理解成绿/紫，应读取实际色值；在 V03 分别为浅蓝/深蓝。
- 按类别数选色，不必用满。V03 三种蓝色较接近，浅暖及灰色优先辅助用途，炭黑优先文字用途，不将八色机械视作八个等价分类色。配合点形、线型、标签或分面保证辨识。
- 默认白底；背景仅在表达阶段、区域或分组时用浅色并标注。背景渐变也须有连续语义，不作装饰。
- 连续数值色标独立遵循数据语义，不套用分类色序或大面积填充强度。相关系数使用当前 blue—白—coral 对应负—零—正，范围 [-1,1] 并标注色条；其他量使用语义合适且亮度有序的色标，跨图比较保持尺度一致。
- 检查最终尺寸、文字对比与灰度可读性，必要调整记录原因。两套都是个人配色，不是国赛官方指定色板，不替代科学审计和赛区要求。

## 覆盖、回滚与追溯

用户当次指定颜色时覆盖对应部分，其余延续当前版本。记录本次 baseline_id、实际色值和对象映射，并传递给下游 Skill/渲染器。

单批使用 V02：该批直接读取 V02 快照，不改默认。用户要求默认回滚 V02：将 V02 JSON 快照原样复制到 personal-color-baseline.json，回读确认 baseline_id=personal-cumcm-v02 并校验内容与快照一致。恢复默认 V03 同理复制 V03 快照。保留两份快照和样张，不覆写版本快照；本入口随 active JSON 生效。后续新方案先打样，用户确认后再建立新版本。
